# 标准规范下载器（macOS Apple Silicon）

一个本地工具：联合检索**住房和城乡建设部标准公告**、**全国标准信息公共服务平台**、**国家工程建设标准化信息网**，按任意关键词查找标准，自动合并同名旧版，并下载官方公开的 PDF 原件到指定文件夹。

- 原生 **Apple Silicon（arm64）** 应用，内置 Python 运行时，**不需要安装 Python**。
- 三个官方来源联合检索，覆盖工程建设国标、行标、地方标准、国家标准等。
- 支持任意关键词，例如 `防火`、`数据中心`、`综合管廊`、`人防`、`电气`。
- 按标准号跨来源合并去重，优先保留实施日期最新的一版。
- 自动配对母标准与局部修订条文，例如 `GB 50016-2014（2018局部修订）`。
- 只从住建部官网公告附件下载，不抓取盗版站、不绕过付费墙或登录限制。
- 所有检索、下载都在本机完成，不上传文件，也不收集个人信息。

> 数据快照：**2026-10-17**。住建部公告索引 **3,254 条**；国标平台、工程标准网实时检索；每次最多解析三个来源约 **100 条**记录，合并后展示前 **60 项**。

> Git 仓库只保存源码、数据和界面资源；`标准规范下载器.app` 与 `标准规范下载器-*.zip` 属于打包产物，不纳入 Git，发布时通过 GitHub Releases 单独上传。

## 1. 快速开始

### 方式 A：双击应用（推荐）

1. 双击 `标准规范下载器.app`。
2. 浏览器自动打开本地界面（`http://127.0.0.1:8765/`）。
3. 输入关键词，点击“搜索公告”或按回车。工具会同时查询三个来源。
4. 选择保存文件夹，勾选结果，点击“下载选中文件”。
5. 完成后点“在 Finder 中打开”。

如果 macOS 提示“无法打开，因为无法验证开发者”：

- 在 Finder 中右键点击 `标准规范下载器.app` → **打开** → 再点“打开”；或
- 在终端执行（仅对从网络传到本机的文件需要）：

```bash
xattr -dr com.apple.quarantine "/path/to/标准规范下载器.app"
```

### 方式 B：命令行

需要 Python 3.9+（macOS 自带的 `/usr/bin/python3` 通常可用；应用本身不需要）。

```bash
cd /path/to/PJ_DSH

# 启动本地网页界面
python3 -m standards_fetcher.cli serve

# 三站联合检索
python3 -m standards_fetcher.cli discover 防火
python3 -m standards_fetcher.cli discover 数据中心
python3 -m standards_fetcher.cli discover GB50054

# 更新公告索引（前 3 页，约 60 条最新公告）
python3 -m standards_fetcher.cli refresh --pages 3

# 深度更新全部公告索引（约 163 页、3,254 条，约 1 分钟）
python3 -m standards_fetcher.cli refresh --full

# 查看数据统计
python3 -m standards_fetcher.cli info
```

也可以双击根目录的 `启动标准规范下载器.command`；它会优先打开 `.app`，找不到时回退到 Python 源码。

## 2. 多源检索原理

1. **住建部公告**：在本地保存的 3,254 条公告标题中检索，解析正文，提取标准号、实施日期、替代关系和 PDF 附件。
2. **全国标准信息公共服务平台**（std.samr.gov.cn）：检索国家标准、行业标准、地方标准、团体标准，读取标准号、名称、状态、发布日期、实施日期和详情页。
3. **国家工程建设标准化信息网**（ccsn.org.cn）：检索工程建设国标、行标、地方标准，补充住建部公告未覆盖的工程标准。
4. **过滤噪声**：排除标题中含“征求意见”“英文版”“产品标准”“标准图集”的公告，以及“废止”状态。
5. **跨来源合并**：按标准号（去掉年份）分组，选择实施日期最新的一版；住建部有 PDF 时优先保留下载能力。
6. **局部修订配对**：住建部公告中的“局部修订”会和母标准放在同一条结果中。
7. **标准号回退**：直接输入 `GB50054`、`GB 50016` 等标准号时，会同时查询三个来源，并回退到内置标准索引。
8. **下载与详情**：只有住建部公告附件提供 PDF 下载；国标平台和工程标准网提供官方详情页。未公开全文的条目给出购买/阅读入口。
9. **下载前复核**：每次下载重新读取公告页，解析最新附件地址，校验 `%PDF` 文件头和文件大小，并计算 SHA-256 写入清单。

### 实测示例

| 关键词 | 三站命中 | 合并后 | 说明 |
| --- | --- | --- | --- |
| 防火 | 589 条记录 | 63 项 | 住建部 38、国标平台 418、工程标准网 133 |
| 数据中心 | 267 条记录 | 20 项 | 含 GB 50174、GB 51195、GB 50462、地方标准等 |
| GB50054 | 2 条记录 | 1 项 | 住建部 + 工程标准网合并为《低压配电设计规范》 |

> “三站命中”是各来源返回的记录数之和，包含重复、不同版本和不同标准类型；“合并后”才是按标准号去重后的条目数。

### 结果分类与排序

结果表上方会按标准号前缀生成类型筛选：

`GB`、`GB/T`、`GB/Z`、`JGJ`、`JGJ/T`、`CJJ`、`CJJ/T`、`JG/T`、`DB`、`DG`、`团体`、`其他`

每个类型显示当前结果数量；点击即可只看该类型。

排序规则：

1. **可直接下载的条目优先**；
2. 同一组内保持原相关度和版本顺序；
3. 类型筛选后，仍保持“可下载优先”。

住建部公告附件可直接下载；国标平台、工程标准网条目没有 PDF 附件，会排在后面，并提供“详情 / 购买阅读”入口。

## 3. 下载与输出

默认保存到：

```text
~/Downloads/建筑电气规范/
```

也可以选择任意用户目录。每次下载会在目标文件夹生成：

```text
GB 50016-2014 建筑设计防火规范.pdf
GB 50016-2014 建筑设计防火规范（2018局部修订）.pdf
_标准清单.csv          # Excel 可直接打开（UTF-8 BOM）
_标准清单.json         # 机器可读清单
_下载报告.md           # 本次下载结果与来源说明
```

清单字段包括：标准号、名称、实施日期、状态、是否含局部修订、官方 PDF 状态、保存路径、文件大小、SHA-256、公告来源、备注。

每个结果下方会显示来源标签：

- `住建部`：可下载官方公告 PDF；
- `国标平台`：全国标准信息公共服务平台，提供标准详情和状态；
- `工程标准网`：国家工程建设标准化信息网，提供工程建设标准详情。

已有文件默认跳过；需要重新下载时，命令行加 `--force`（网页端暂未提供强制覆盖开关）。

## 4. 为什么有些 PDF 下载不了

住建部公告并不总是附全文。常见情况：

- 公告只发布了标准编号和实施日期，没有 PDF 附件；
- 公告只公开局部修订条文，母标准全文需要购买；
- 标准属于其他部委、地方标准、图集或产品标准，不在住建部公告库内；
- 标准已废止，新版公告尚未收录。

工具会显示“未公开”，并提供“公告”和“购买/阅读”入口，例如：

- GB 50054-2011《低压配电设计规范》
- GB 50057-2010《建筑物防雷设计规范》
- GB 50052-2009《供配电系统设计规范》

请通过中国建筑出版传媒、国家标准馆等正规渠道购买或在线阅读。PDF 版权归出版单位所有，下载文件仅供个人学习、研究或项目内部查阅。

  - `settings.json`：上次选择的保存文件夹
  - `app.log`：运行日志

“更新公告库”默认抓取前 3 页（约 60 条最新公告）；命令行 `refresh --full` 可抓全部 163 页。

## 6. 开发与打包

### 源码结构

```text
standards_fetcher/
  cli.py          命令行
  web.py          本地 HTTP 服务与 API
  discovery.py    三站联合检索、跨来源合并、局部修订配对
  sources.py      国标平台 / 工程标准网适配器
  mohurd.py       住建部公告抓取/解析
  downloader.py   下载、校验、清单
  catalog.py      标准号回退与内置目录
  util.py         路径、HTTP、文件名、macOS 辅助
  data/           公告索引、内置回退目录
  static/         单页界面（HTML/CSS/JS）
tests/            解析、目录、版本合并单元测试
tools/            打包辅助脚本
run.py            PyInstaller 入口
```

### 运行测试

```bash
python3 -m unittest discover -s tests -v
```

### 重新打包 macOS 应用

在 Apple Silicon Mac 上：

```bash
chmod +x tools/build_macos.sh
./tools/build_macos.sh
```

脚本会调用 PyInstaller 打包 `run.py`、`data/`、`static/`，生成 arm64 `.app` 并进行 ad-hoc 签名。需要 Python 3.9+、PyInstaller、Pillow，以及 Xcode Command Line Tools（提供 `lipo`）。

## 7. 常见问题

**Q：为什么打开后浏览器地址是 127.0.0.1？**
A：应用在本机启动一个只监听 `127.0.0.1` 的小型服务，页面和下载都在本机完成，不经过外网服务器。

**Q：搜不到某个标准怎么办？**
A：工具覆盖住建部公告、国标平台和工程建设标准网；仍可能有未收录的团体标准、企业标准、图集或非常新的公告。可换用更短的核心词，或到标准所属部委/地方住建部门查询。

**Q：提示“来源较多，仅解析部分”是什么意思？**
A：三个来源命中总数较多时，为保证速度只解析前一部分记录，合并后最多展示 60 项；使用更精确的关键词可以获得更完整的结果。

**Q：下载的 PDF 能用于商业项目吗？**
A：PDF 版权归标准出版单位所有。本工具仅帮助你获取官方公开文本；商业使用、批量分发请遵守版权规定并购买正式版本。

**Q：如何退出？**
A：点击页面右上角“退出”。直接关闭浏览器标签页不会停止后台服务；也可以在“活动监视器”中退出“标准规范下载器”。
